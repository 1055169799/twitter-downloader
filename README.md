# Twitter下载器（无广告版）

一个简单、干净、无广告的 Twitter/X 视频与图片下载器。

## 功能特性

- 粘贴推文链接一键解析，自动列出可下载的视频/图片
- 显示每个媒体的分辨率与文件大小
- 下载过程实时显示进度条与百分比
- 多文件并行下载，逐项独立进度
- 点击已下载文件直接用系统图片/视频应用打开
- 下载记录带缩略图预览
- 「查看原文」一键跳转 X(Twitter) 打开原始推文
- 支持从其他应用分享推文链接进入本应用
- 无广告、无多余权限、无数据收集

## 使用方法

1. 在 X(Twitter) 中打开任意推文，点击「分享」选择本应用；或复制推文链接，在本应用输入框中粘贴
2. 点击「解析」，选择需要的分辨率开始下载
3. 下载完成后可在「最近下载」中打开或分享文件

## 常见问题

**Q: 受保护/私密推文无法解析？**
A: 受保护账号或仅粉丝可见的推文需要登录态，当前版本暂不支持，请先确认推文是公开可见的。

**Q: 下载的文件在哪里？**
A: 默认保存在系统下载目录的 TwitterDownloader 文件夹中。

**Q: GitHub 链接打不开？**
A: 请使用上方入口 2（加速镜像）或入口 3（Gitee 直链）。
